Les Core Web Vitals expliqués simplement

27 août 2026 · 7 min de lecture

Les Core Web Vitals sont les métriques de performance que Google utilise pour évaluer l'expérience utilisateur de votre site. Depuis 2021, ils influencent directement votre référencement. Voici ce qu'il faut comprendre.

Qu'est-ce que les Core Web Vitals ?

Les Core Web Vitals (CWV) sont trois métriques qui mesurent la qualité de l'expérience utilisateur sur votre site. Google les utilise comme facteur de ranking : un site avec de bons scores CWV est mieux référencé.

LCP — Largest Contentful Paint

Le LCP mesure le temps d'affichage du contenu principal. C'est le moment où l'utilisateur voit le contenu le plus important de la page.

  • Bon : < 2.5 secondes
  • À améliorer : 2.5s — 4s
  • Mauvais : > 4 secondes

Comment l'améliorer : Optimiser les images (WebP, compression), utiliser un hébergement rapide, implémenter le lazy loading.

INP — Interaction to Next Paint

L'INP mesure la réactivité du site. C'est le temps de réponse du navigateur après une interaction utilisateur (clic, saisie, scroll).

  • Bon : < 200 millisecondes
  • À améliorer : 200ms — 500ms
  • Mauvais : > 500ms

Comment l'améliorer : Réduire le JavaScript bloquant, optimiser les event handlers, utiliser requestIdleCallback.

CLS — Cumulative Layout Shift

Le CLS mesure la stabilité visuelle. C'est le décalage inattendu des éléments pendant le chargement de la page.

  • Bon : < 0.1
  • À améliorer : 0.1 — 0.25
  • Mauvais : > 0.25

Comment l'améliorer : Définir les dimensions des images et vidéos, éviter d'insérer du contenu au-dessus du contenu existant.

Pourquoi c'est important

Les Core Web Vitals ne sont pas juste une métrique technique. Ils impactent directement votre business :

  • SEO : Google utilise les CWV comme facteur de ranking
  • Conversion : Une page qui charge 1 seconde de moins augmente les conversions de 7%
  • Expérience utilisateur : 53% des utilisateurs quittent un site qui met plus de 3 secondes à charger
